05 · Best fit

Choose the medium
for the moment.

PowerPoint

  • Fast manual authoring
  • Familiar review workflow
  • Classic linear storytelling
  • Easy offline handover
VS

HTML

  • Interactive visual storytelling
  • Live or frequently changing data
  • Reusable design systems
  • Browser-based distribution
Takeaway
PowerPoint presents information.
HTML can turn information into an experience.

The advantage is not motion for its own sake. It is the ability to combine narrative, visualization, interaction and reusable code in one medium.
